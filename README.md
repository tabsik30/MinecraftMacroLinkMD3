# MacroLink — mod Fabric

Client-side mod na Minecraft 26.2, który co ~4x/s wystawia dane gracza
przez lokalny serwer WebSocket (`ws://127.0.0.1:25599`):

Plugin form MD3 that shows minecraft stats on MD3 thre
loacl server WEbSocket (`ws://127.0.0.1:25599`):

```json
{
  "health": 18.0,
  "maxHealth": 20.0,
  "armor": 12,
  "hunger": 15,
  "x": 123.4, "y": 64.0, "z": -876.2,
  "dimension": "minecraft:overworld",
  "biome": "minecraft:plains",
  "timeOfDay": 13500,
  "air": 300,
  "maxAir": 300,
  "xpLevel": 7,
  "xpProgress": 0.42
}
```
